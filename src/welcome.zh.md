# Moss

一个安静的 Markdown 编辑器。你在文字里写，页面在你周围慢慢成形——没有预览窗格，因为你读到的这句话本身就是源码。

> 好的工具会消失，剩下的是你本来想写的那句话。

## 已经能用的

- **实时排版** —— 标题、**粗体**、*斜体*、`行内代码`、~~删除线~~、[链接](https://example.com)，边写边变。
- **结构** —— 引用、列表、任务清单、分割线都画在原位。
- **公式** —— 行内 $E = mc^2$，以及独立成行：

$$\int_{-\infty}^{\infty} e^{-x^{2}}\,dx = \sqrt{\pi}$$

- **代码** —— 围栏代码块保留语法高亮，围栏本身会淡出。
- **表格** —— 渲染成真表格，点进单元格直接改。

### 代码

```ts
type Note = { title: string; body: string };

export function wordCount(note: Note): number {
  const cjk = (note.body.match(/[\u4e00-\u9fa5]/g) ?? []).length;
  const latin = note.body.replace(/[\u4e00-\u9fa5]/g, ' ').split(/\s+/).filter(Boolean).length;
  return cjk + latin;
}
```

### 快捷键

| 操作 | 快捷键 | 说明 |
| --- | --- | --- |
| 实时 / 源码 | `Ctrl` + `/` | 切换语法层 |
| 专注模式 | `Ctrl` + `Shift` + `F` | 只亮你正在写的这一段 |
| 打字机模式 | `F8` | 光标锁在屏幕中间 |
| 加粗 / 斜体 | `Ctrl` + `B` / `Ctrl` + `I` | 包住选中的文字 |
| 标题 | `Ctrl` + `1` … `6` | `Ctrl` + `0` 取消标题 |
| 保存 | `Ctrl` + `S` | 写回打开的文件 |
